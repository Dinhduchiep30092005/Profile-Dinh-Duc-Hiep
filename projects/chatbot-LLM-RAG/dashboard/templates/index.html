📋 Hướng dẫn cài đặt

  1. Tạo GCP Project tại Google Cloud Console
  2. Bật Search Console API trong APIs & Services
  3. Tạo Service Account → tải file JSON key
  4. Vào GSC → Settings → Users → thêm email service account
